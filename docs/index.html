01The number

The number other cleaners sell you is usually cache.

macOS fills spare RAM with cache on purpose. It is the fastest thing your Mac can do with memory it isn't using, and it yields the moment an app asks for it. Counting it as “used” makes the problem look bigger than it is.

Physical memory 16.00 GB Live readout 11.11 GB in use
Available on demand
3.20 GB
3.53 GB
4.38 GB
3.75 GB cached
04 GB8 GB12 GB16 GB

Cached memory is available memory. Files kept in RAM because nothing else needed it. The instant an app asks, macOS hands it over. A big cache is a Mac using spare memory well, not a Mac that is full.

How a cleaner reads it

14.86 GB used

Big warning number. “Clean 3.75 GB.” It would shrink memory macOS is using well, and leave the Mac slower.

What is actually true

11.11 GB genuinely spoken for

3.75 GB of that is cache, handed back the instant an app asks. 4.89 GB available without closing anything.

A high cache is a healthy Mac. Not a full one.

03Pause

Pause is not quit.

Quitting throws away where you were. Pause freezes the app and every helper: no CPU, no state lost, and macOS is free to move its pages to disk. Switch back and it resumes exactly where it was.

Mechanism
SIGSTOP, not a kill. The app and its helpers freeze as one.
While paused
0.0% CPU. State stays in memory; the pages become eligible to swap.
Watchdog
If Boost crashes or is killed, everything it froze is resumed. Nothing stays stuck.
Automatic
Optional: pause apps after 5 to 60 minutes in the background. Wakes the moment you switch to them.
Figma · Untitled

04Disk

Clean only what can prove it's disposable.

Boost scans a short allowlist. A folder is listed only when the manifest next to it proves what it is, and nothing is ticked for you. Removing files should be a decision, not a default.

Scan result Nothing pre-ticked
0 B selected of 11.49 GB
Selection demo only. This page deletes nothing. Caches are deleted · everything else goes to the Trash

Never scanned

If it can't be proven safe, it isn't listed.

  • Downloads
  • Any node_modules
  • iOS device backups
  • Music, Photos, Safari caches
  • Xcode Archives, unless you tick them yourself
  • Anything behind a privacy prompt

If proving it is safe would need a permission prompt, Boost skips it instead of asking.

The second check

Two gates before anything is deleted.

First, the path must be on the allowlist. Then Boost resolves the real path and checks it again immediately before removal.

A symlink sitting in a cache and pointing at your Documents is how tools like this destroy data. There is a test that builds exactly that trap.

Caches are deleted, and the tab says so. Projects, Large Files, AI Models, Uninstall and Xcode Archives move to the Trash. Allowlist + resolved-path check · symlink trap test in the suite · Docker's disk image is shown, never deleted
05History

A week of evidence.

One reading a minute, kept for seven days. Peak, average, and how often your Mac went into swap, so “was it slow at 3pm yesterday” has an answer instead of a guess.

You pick the line.

It tells you when swap crosses the threshold you chose, not every time the number moves.

One full minute

Pressure has to last.

A spike that passes on its own is ignored. A minute of tight memory gets a notification naming the app using the most.

Pause, never close

The alert can't quit anything.

It can pause apps you ticked. It cannot close them. There is a test for that, because it matters.

07

boost.sh

The same job without a window: close, pause, resume, dry-run. Pins are written to a file the script and the app both read, so a hotkey and the menu bar agree.

CLI
boost.sh · zsh

07Install

Install it in one line.

Homebrew clears the quarantine flag for you. Building from source never sets one, and needs only the Command Line Tools, not Xcode.

On signing, plainly

Boost is signed with a local certificate, not notarized. Notarizing needs a paid Apple Developer account, which a free app does not have. The Homebrew cask clears the quarantine flag. A source build never sets one. Read the full note.

macOS 14+ · Apple Silicon + Intel · one universal binary · GPL-3.0

$ brew install --cask kernel-hunter/boost/boost
