How to free up RAM on a Mac: what works and what does not

Most of the time you do not need to free any RAM. A Mac that shows very little free memory is behaving normally, because macOS fills spare RAM with cached files. What matters is memory pressure. If the graph in Activity Monitor is green, leave the Mac alone. If it stays yellow or red, quit or pause the heaviest apps, close browser tabs and trim your login items. A tool that "cleans" RAM gives you a better looking number for a few minutes and fixes nothing.

Read memory pressure, not free memory

Open Activity Monitor (Applications, then Utilities) and click the Memory tab. The graph at the bottom is Memory Pressure. Apple's description is short: green means the Mac is using its RAM efficiently, yellow means it might eventually need more, and red means it needs more RAM now. Apple also says the graph is based on free memory, swap rate, wired memory and file cached memory, so it tracks how hard macOS is working to find room.

Look at Swap Used next to it. A small, steady amount of swap is ordinary. Swap that keeps growing while you work is worth acting on. The memory pressure guide goes through all of this in more detail.

What cached and compressed memory are

Cached Files is the contents of files macOS read recently and kept in otherwise unused RAM so the next read is quick. macOS gives that space back when an app asks for it, so it is not wasted memory. The cached memory guide covers it.

Compressed memory is data from idle apps that macOS squeezes into less space instead of writing it to the disk. Compressing is usually cheaper than swapping to the SSD, which is why a Mac with a lot of compressed memory can still feel fine.

Why RAM cleaners do not help

Many RAM cleaners run the purge command or something like it. Apple's own manual page describes purge as a way to approximate a cold start for performance analysis, and says it does not affect memory that apps have allocated. So it throws away the file cache. The number you watch improves, and then every file you need is read from the disk again, which makes things feel slower until the cache fills back up.

The same goes for any tool that shows cached memory in red and offers to clear it.

What actually helps

If pressure really is yellow or red, work through these in order.

  1. Find the heavy apps. In the Memory tab, click the Memory column to sort. Browsers split into many processes, so check the browser's own task list too. Quit what you are not using. Closing a window often leaves the app running, so use Command-Q.
  2. Close browser tabs you are finished with. Chrome has a Memory Saver setting that frees memory from tabs you are not looking at.
  3. Trim login items. In System Settings, go to General, then Login Items & Extensions (the exact name varies a little between macOS versions). Anything that opens at login and sits in the background uses memory all day. Apple's page on login items shows where to look.
  4. Quit and reopen the one app that has grown to many gigabytes. That clears a slow leak without touching anything else.
  5. Restart if the Mac has been up for weeks and pressure stays yellow after you have quit the big apps. A restart is rarely needed otherwise.

Apple silicon and buying more

On Apple silicon the memory sits in the same package as the processor and is shared between the CPU and the GPU. You cannot add RAM later, so the amount you buy is the amount you keep. Some older Intel Macs do let you upgrade.

Buy more only if memory pressure is regularly yellow or red during your normal work, after you have dealt with the items above. If the graph is green most of the day, more RAM will not make the Mac faster.

Boost has a Free Memory button, so here is what it does and does not do. It runs Apple's memory_pressure tool, which allocates memory until macOS decides it is running low. That makes macOS compress and release idle pages. Boost reads the memory figures before and after and reports only what actually stopped being used, and it stops early if swap starts to grow. In practice that is often a few hundred MB, and up to about 1 GB. It is a small nudge. If pressure is red, quit or pause the heavy apps instead.

Boost is free and open source (GPL-3.0) and shows pressure, swap, cached and compressed memory from the menu bar. It is not notarized by Apple, so the first launch needs an extra step, described on its home page.
